# 5段階ホイールズーム（2026-09-27）

Overviewと手動経路編集のズームを5段階へ変更。軽い入力でも1段動き、入力値の大きさによる移動量の差をなくした。同方向で短く続く入力は1回にまとめ、暫定0.18 UI秒の無入力後に次の段階を受け付ける。逆方向は直ちに受け付ける。

ズームイン・アウトとも暫定0.3 UI秒で対数サイズをSmoothStep補間する。反転時はその時点の画角から補間し直す。追加指示により、ホイール開始時のマウス位置を中心に、対象が同じ画面位置に留まるようカメラと旋回中心も水平移動する。向き・高度とゲーム時間を維持し、Pause中も進む。UI操作中・カメラ表示領域外のホイールは除外する。F／Home・Source一覧・Esc・カメラ切替では残りの補間を破棄する。

アニメーション中にマウスだけを動かしてもズーム中心は変わらない。次のホイール操作を受理した時点で新しいマウス位置へ切り替える。平行投影の画角変化を水平移動で補正するため、地面だけでなく屋上・高所Nodeも同じ画面位置を保ち、Colliderの有無に依存しない。

最接近のorthographicSizeは暫定8 m。全景を4段階目、その2倍を5段階目とし、近い側の3区間を等倍率にする。東京駅では遠方から440、220（Home）、72.886、24.147、8 mとなる。範囲や時間は操作感を調整できる暫定値。
